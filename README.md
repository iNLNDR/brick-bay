# Brick Bay Academy

A pirate-island learning game for Cambridge Primary **Maths, Science and English** (Stages 1–6).
Kids earn XP and coins, unlock pixel characters, hatch pets, and save coins for real rewards a grown-up approves.

Works in any browser on iPad, iPhone, Android and computers. No login, no server, works offline after the first visit.

## Put it online with GitHub Pages (free)

1. Sign in at github.com and click **New repository**. Name it `brick-bay` and make it **Public**. Click **Create repository**.
2. On the new repo page click **uploading an existing file**. Drag in all the files from this folder
   (`index.html`, `manifest.webmanifest`, `sw.js`, the three `icon-*.png` files and this README). Click **Commit changes**.
3. Go to **Settings → Pages**. Under **Branch** choose `main` and `/ (root)`, then **Save**.
4. Wait about a minute. Your game is at `https://YOUR-USERNAME.github.io/brick-bay/`

## Install it like an app

- **iPad / iPhone:** open the link in Safari → Share button → **Add to Home Screen**.
- **Android:** open in Chrome → menu (⋮) → **Install app** or **Add to Home screen**.

## Good to know

- Progress is stored on each device. To move a child's progress, use **Grown-ups → Move to another device** (copy the save code on one device, paste it on the other).
- Set a **parent PIN** in Grown-ups so kids can't approve their own rewards.
- Change rewards and prices in **Grown-ups → Reward shop**.
- After editing files, change `VERSION` in `sw.js` so devices pick up the new version.
